# Recorded walkthrough script

A script for the recorded walkthrough required by Hard Stop 5. Target length 8 to 10 minutes. Record the screen with a terminal and a file browser or editor side by side. Run every command live; do not paste prepared output.

Before recording: open a terminal in the repository root, run `make clean` so nothing is prebuilt, make sure ports 7878, 6380, 5433 and 27018 are free, and increase the terminal font size.
